# Hospital Database Design and SQL
## Project Overview
This was a Database Fundamentals university project at TU Dublin. I designed a hospital database to organise information about patients, staff, departments, treatments and appointments.
## Tools and Skills
- SQL
- Database design
- ER diagrams
- Primary and foreign keys
- Database normalisation (3NF)
- SQL queries
## What I Did
I identified six main entities for the hospital database and designed their relationships. I created conceptual, logical and physical ER diagrams.
I also wrote SQL statements to create tables, add sample records and work with the database using different queries.
## Project Outcome
This project helped me understand how relational databases are designed, how tables connect using keys and how SQL can be used to manage information.
